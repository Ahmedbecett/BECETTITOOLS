## Full description — 4000 characters max

```
BECETTI TOOLS puts fifteen everyday utilities in a single Android app, built natively
with Kotlin and Jetpack Compose. No account, no subscription, no sign-in screen — and the
core tools keep working with the network switched off.

WHAT'S INSIDE

Calculator & converters
• Scientific Calculator — arithmetic, powers, square root, percentages, sin/cos/tan in
  degrees, log and ln. Every result can be kept in a local history.
• Unit Converter — length, weight, temperature, area, volume and speed, converting both
  ways as you type.
• Currency Converter — reference rates from the Frankfurter API (European Central Bank
  data), cached on the device with a last-updated timestamp and an offline indicator.
• Percentage Calculator — percentage of a number, increase and decrease.

QR and security
• QR Code Generator — text, URL, Wi-Fi network or contact card, exported as a PNG to
  Pictures/Becetti.
• QR Code Scanner — CameraX preview with on-device ML Kit decoding. The camera is only
  requested when you open the scanner, and links open only after you confirm.
• Password Generator — 4 to 64 characters from SecureRandom, with independent toggles
  for upper case, lower case, digits and symbols. Nothing is stored or uploaded.
• Password Strength Checker — a local 0-5 analysis that never leaves the device.

Documents and files
• Image to PDF — pick several images, keep them in order, export A4, A3 or Letter to
  Documents/Becetti. Your originals are never modified.
• PDF Merger — combine PDFs in selection order and save the result.
• OCR Text Extractor — pull text out of a photo or screenshot with on-device ML Kit
  recognition (Latin script: English, French and similar).

Images and text
• Image Compressor — quality slider with a live preview, saved as JPEG.
• Text Toolkit — word and character counts, case changes, duplicate-space and empty-line
  cleanup, reverse.
• Notes Manager — create, edit, search and delete notes in a local Room database.

Date and time
• Age Calculator — exact age in years, months and days, the next birthday, and the
  difference between two dates.

PRIVACY BY DESIGN
• No account, no analytics SDK, no advertising identifier.
• Notes, favourites and history stay in a local database on your phone.
• QR decoding, OCR, PDF creation and password generation run on the device.
• The only network request the app makes is for reference exchange rates; it sends the
  currency codes and nothing about you.
• Permissions are requested only when a tool needs them, with an explanation first.

LANGUAGES AND COMPATIBILITY
• Interface in English, French and Arabic, with a right-to-left layout for Arabic.
• Android 7.0 (API 24) and newer; compiled against API 34.
• Works offline except for live currency rates.

OPEN SOURCE
The full Kotlin source is published under the MIT licence, so every statement above can be
checked against the code that produced this build.

Built by Ahmed Becetti. Feedback and translation corrections are welcome by email or
through the project's issue tracker.
```
3,050 characters, comfortably inside the limit.
