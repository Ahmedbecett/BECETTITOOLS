BECETTI TOOLS

Everything you need. One smart toolbox.

Fifteen focused tools for everyday work — calculations, conversions, QR codes, PDFs, images and text — built natively with Kotlin and Jetpack Compose. No account, no subscription, and the core tools keep working with the network switched off.

This APK is a debug build

It is debuggable and signed with a debug key, not with a production/Play signing key. Install it to evaluate the app; it is not a store-ready release. The exact file published here is the one committed in the repository.

What this app does with your data

  • No account, no tracking

    There is no sign-in, no analytics SDK and no advertising identifier in v1.0.0. Notes, favourites and history stay in a local database.

  • On-device processing

    QR decoding, OCR, PDF creation and password generation all run on the phone. Passwords are never stored or uploaded.

  • Permissions on demand

    Camera is requested only when you open the QR scanner. Files are chosen through the Android system picker, not by scanning your storage.

  • Open source

    The full Kotlin source, including every tool listed below, is public under the MIT licence. You can read, rebuild and audit it.

Installation instructions

Five steps, about a minute, on any phone running Android 7.0 or newer.

  1. 1

    Download the APK

    Use the download button above on the phone itself, so the file lands in your Downloads folder.

  2. 2

    Allow installing from this source

    When Android asks, open Settings and enable “Install unknown apps” for your browser or file manager. This is a per-app Android permission; the app itself cannot change it.

  3. 3

    Open the file and install

    Tap the downloaded file, review the permissions Android lists, then choose Install.

  4. 4

    Expect a Play Protect notice

    An APK that did not come from Google Play can raise a “scan for harmful apps” prompt. Choose to install anyway only if you verified the checksum in the previous step.

  5. 5

    Grant permissions as you use the app

    Camera is only requested when you open the QR scanner, and file access only when you pick images or PDFs. Everything else works without granting anything.

If installation fails

  • “App not installed” usually means an older debug build is already installed. Uninstall it first — the debug install ID is com.becetti.tools.debug.
  • “There was a problem parsing the package” usually means the download was incomplete. Re-download and compare the checksum.
  • If you need to keep data from an older build, do not uninstall blindly: export your notes first.
  • This APK contains arm64-v8a, armeabi-v7a, x86 and x86_64 libraries, so it installs on phones and on most emulators.

Uninstalling removes the local database along with the app. Notes and history are not backed up anywhere.

Privacy in plain language

The full policy is published on its own page in all three languages. The short version: nothing you type, scan or convert is uploaded.

  • Notes, favourites, recent tools and calculator history are stored in a local Room database on the device.
  • Camera frames from the QR scanner are decoded on the device by ML Kit and are not saved.
  • Images and PDFs are read through the Android Storage Access Framework and processed locally; outputs are written to Pictures/Becetti and Documents/Becetti.
  • The currency converter sends only currency codes to api.frankfurter.app over HTTPS, and caches the result with a timestamp.
  • Generated and checked passwords never leave the device and are never written to storage.
  • Advertising consent is stored as a local flag. In v1.0.0 no advertising SDK is initialised and the optional “Sponsored Offers” row opens only when you tap it.

Frequently asked questions

Is BECETTI TOOLS free?

Yes. v1.0.0 is free to download and has no subscription, no account and no paywalled tool. The source is MIT-licensed.

Does it work without internet?

Every tool except the live currency update works offline. The currency converter shows cached rates with their last-updated time and an offline indicator.

Why is this APK labelled a debug build?

It was built with the Android Gradle plugin’s debug variant, so it is debuggable and signed with a debug key. That is stated openly instead of being presented as a store release. A signed release build is on the roadmap.

Which Android versions are supported?

Android 7.0 (API 24) and newer. It is compiled against API 34 (Android 14) and uses the Android 13+ media permissions. Newer Android versions are expected to work but are not part of the tested baseline.

Why is the app about 89 MB?

The file is 88,869,105 bytes — 88.9 MB in decimal, which is what your phone's file manager shows, or 84.8 MiB in binary. Most of it is the bundled on-device machine-learning libraries for barcode scanning and text recognition, plus four CPU architectures. That is the price of working offline without sending your camera images to a server.

Are my passwords or notes uploaded anywhere?

No. Passwords are generated with SecureRandom and are never stored. Notes live in the local Room database. There is no sync service in v1.0.0.

Does OCR read Arabic?

The text recognition model bundled in v1.0.0 covers Latin script, so French and English work. Arabic-script OCR needs an additional model and is listed for v1.1.

Will I see ads?

In v1.0.0 no advertising SDK is initialised. A labelled “Sponsored Offers” row can appear on the home screen; it opens an external page only when you tap it, never automatically. The calculator screen never shows ads.

Is there an iOS or web version?

No. The app is native Android only (Kotlin, Jetpack Compose, Material 3).

How do I uninstall and remove my data?

Uninstall the app from Android settings. The local database is deleted with it. There is no server-side copy to delete.
