# Screenshots and previews

## What exists today

The landing page ships **six illustrative UI previews** in `website/assets/img/previews/`:

| File | Screen | Notes |
|---|---|---|
| `home.svg` | Home | Search field, categories grid, tool list, labelled “Sponsored Offers” row, bottom navigation |
| `calculator.svg` | Scientific Calculator | Dark theme, expression + result, log/ln/%/trig keypad |
| `qr.svg` | QR Generator | Text/URL/Wi-Fi/Contact chips, QR preview, export button |
| `pdf.svg` | Image to PDF | Multi-image selection, page size, order list, save path |
| `converter.svg` | Unit Converter | Six categories, from/to fields, swap, result |
| `settings-rtl.svg` | Settings (Arabic) | Right-to-left layout, Arabic labels, privacy rows |

They are **vector mock-ups rebuilt from the Compose screens and the app palette**
(`#F47B20`, `#D96513`, `#FFF0E2`, `#172235`, `#263B57`). They are not device captures, and every
caption on the site says so explicitly. They are generated by `scripts/site/previews.mjs`, so they
update automatically when the markup changes.

Also generated: `website/assets/img/og-image.png` (1200×630 link preview) and the icon set
(`logo.svg`, `logo-192.png`, `logo-512.png`, `favicon.svg`, `favicon-32.png`,
`apple-touch-icon.png`) via `bash scripts/make-images.sh`.

## How to add real screenshots

Real captures should replace the previews as soon as a device is available. Nothing else on the
site has to change.

1. **Capture** on Android 13 (a Pixel-class device and a low-end device is ideal):
   Home, Calculator, QR Generator, Image to PDF, Unit Converter, and Settings with the app
   language set to Arabic.
   - Light theme for Home / QR / PDF; dark theme for Calculator / Converter; Arabic for Settings.
2. **Crop** to the phone screen only (no desktop, no mockup frame), 1080 px wide, PNG or WebP,
   ≤ 200 KB each after optimisation.
3. **Save** into `website/assets/img/previews/` using the same names as the table above, with a
   `.png` extension.
4. **Point the markup at them:** in `scripts/site/render.mjs`, change the `.svg` extension to
   `.png` in `heroSection()` and `previewSection()`.
5. **Update the wording:** in `scripts/site/i18n/pages.mjs`, replace the `previews.disclaimer`
   strings (EN/FR/AR) with a normal caption, since they will no longer be mock-ups.
6. **Rebuild and verify:**
   ```bash
   node scripts/build-site.mjs && node scripts/verify-site.mjs
   ```
   The verifier checks that every referenced image exists and that each has `alt`, `width` and
   `height`.
7. **Delete** the obsolete SVGs, or keep them as a design reference.

## Rules

- Do not invent screenshots, ratings or download counts — if a screen is not captured, say so.
- Do not screenshot personal notes, generated passwords or real QR payloads; use demo content.
- Keep images compressed; the whole site is currently ~430 KiB and should stay in that range.
